Motivación

¿Por qué integrar numéricamente?

Sin antiderivada

Muchas funciones no tienen primitiva elemental: $e^{-x^2}$, $\frac{\sin x}{x}$, $\sqrt{1+x^4}$.

Solo hay datos

En un experimento no tenemos $f(x)$, tenemos una tabla de mediciones.

La idea central

Reemplazar $f$ por un polinomio interpolante e integrar ese polinomio, que sí sabemos integrar.

Conexión con el Cap. 2

Integrar numéricamente $=$ interpolar $+$ integrar exacto. El grado del polinomio define la regla.

PolinomioRegla resultantePuntos
Recta (grado 1)Trapecio2
Parábola (grado 2)Simpson 1/33
Cúbica (grado 3)Simpson 3/84
Grado $N$Newton-Cotes $N$$N+1$
La regla más simple

Regla del Trapecio

Se une cada par de puntos con una recta

$$I \approx \frac{h}{2}\left[f_0 + 2\sum_{j=1}^{N-1}f_j + f_N\right]$$
Los pesos

1, 2, 2, …, 2, 1
El 2 aparece porque cada punto interior es compartido por dos trapecios adyacentes.

Error

$$E \approx -\tfrac{1}{12}(b-a)h^2\bar{f}''$$ Es $O(h^2)$: al duplicar $N$, el error se divide por 4.

Parábolas en vez de rectas

Reglas de Simpson

REGLA 1/3  ·  $N$ par

$$I \approx \frac{h}{3}\bigl[f_0 + 4f_1 + 2f_2 + \cdots + f_N\bigr]$$

REGLA 3/8  ·  $N$ múltiplo de 3

$$I \approx \frac{3h}{8}\bigl[f_0 + 3f_1 + 3f_2 + f_3\bigr]$$
Pesos de la regla 1/3

1, 4, 2, 4, 2, …, 4, 1
Alternan $4$ (impares) y $2$ (pares), con $1$ en los extremos.

Error

$$E \approx -\frac{(b-a)h^4}{180}f^{(iv)}$$ Es $O(h^4)$: al duplicar $N$ el error se divide por 16.

El bonus de simetría

Aunque la parábola es de grado 2, Simpson 1/3 integra exactamente también las cúbicas — gana un orden de regalo.

¿Por qué unas reglas ganan a otras?

Análisis de error

ReglaError de truncamientoOrdenExacta si $f$ es…
Trapecio $E \approx -\dfrac{1}{12}(b-a)\,h^2\,\bar{f}''$ $O(h^2)$ recta (grado $\leq 1$)
Simpson 1/3 $E \approx -\dfrac{(b-a)h^4}{180}f^{(iv)}$ $O(h^4)$ cúbica (grado $\leq 3$)
Simpson 3/8 $E \approx -\dfrac{3}{80}h^5 f^{(iv)}$ $O(h^4)$ cúbica (grado $\leq 3$)
Newton-Cotes $N=4$ $E \approx -\dfrac{8}{945}h^7 f^{(vi)}$ $O(h^6)$ grado $\leq 5$
Gauss orden $N$ — exacto grado $\leq 2N-1$
La derivada mide el "desvío"

El error depende de una derivada de orden alto porque mide cuánto se aleja $f$ del polinomio. Si $f$ ya es un polinomio de ese grado, esa derivada vale $0$ y el error desaparece.

Qué pasa al duplicar $N$

$O(h^2)$ → el error se divide por 4
$O(h^4)$ → el error se divide por 16
Eso explica la tabla anterior: Simpson alcanza en $N=4$ lo que el trapecio necesita $N=32$.

$\bar{f}''$ y $f^{(iv)}$ se evalúan en un punto $\xi$ desconocido dentro de $[a,b]$  —  por eso las fórmulas acotan el error, no lo dan exacto.

Programa 4-1 · Nakamura pp. 141–143

Implementación: el caso $N$ impar

El problema

La regla $1/3$ exige $N$ par. ¿Qué hacer si el usuario pide $N=5$?

La solución del libro

Arrancar con 3/8 sobre los 3 primeros intervalos. Lo que queda ($N-3$) ya es par → aplicar $1/3$.

$N=5,\; h=0.4$
3/8 sobre $[0,\ 1.2]$  →  nodos $0,\,0.4,\,0.8,\,1.2$
1/3 sobre $[1.2,\ 2.0]$  →  nodos $1.2,\,1.6,\,2.0$

Código R
if (n %% 2 != 0) { # N impar ls <- 3 # 3/8 consume 3 # ... pesos 1,3,3,1 ... ss <- ss * h * 3/8 } m <- n - ls # resto: PAR for (i in 0:m) { x <- a + h*(i + ls) # desplazado w <- if (i %% 2 == 1) 4 else 2 if (i==0 || i==m) w <- 1 s <- s + w*f(x) }
Dos detalles finos

1. ls desplaza el índice para no recontar nodos ya usados.
2. El if de extremos va después del de paridad — lo sobrescribe.

Ejemplo 4.2 · Extrapolación de Richardson

Integración de Romberg

$$E_h \approx \tfrac{1}{3}\bigl(I_h - I_{2h}\bigr) \qquad\Longrightarrow\qquad I \approx I_h + \tfrac{1}{3}\bigl(I_h - I_{2h}\bigr)$$
La lógica

Si sabemos que $E_h \approx Ch^2$, entonces $E_{2h} \approx 4Ch^2$. Con dos cálculos podemos despejar $C$, estimar el error y restarlo.

El efecto

Eleva la precisión de $O(h^2)$ a $O(h^4)$ sin evaluar ni un punto más.

$I_{h=0.5}\;\; = 11.9895$
$I_{h=0.25} = 11.7940$
─────────────────
$E_{0.25} = \tfrac13(11.7940 - 11.9895)$
$= -0.0652$
─────────────────
$I = 11.7940 - 0.0652 = \mathbf{11.7288}$

Resultado

Con solo 8 intervalos se alcanza la precisión del trapecio con $N=128$.

Programa 4-2 · La generalización

Fórmulas de Newton-Cotes

$$\int_a^b f(x)\,dx \approx \alpha\,h\bigl[w_0f_0 + w_1f_1 + \cdots + w_Nf_N\bigr], \qquad h=\frac{b-a}{N}$$
$N$$\alpha$Pesos $w_i$
1$1/2$1, 1  ← Trapecio
2$1/3$1, 4, 1  ← Simpson 1/3
3$3/8$1, 3, 3, 1  ← Simpson 3/8
4$2/45$7, 32, 12, 32, 7
5$5/288$19, 75, 50, 50, 75, 19
6$1/140$41, 216, 27, 272, …

Todas las reglas anteriores son casos particulares.

Cerradas vs abiertas

Cerradas: evalúan $a$ y $b$. Más precisas.
Abiertas: $w_0 = w_{N+2} = 0$. Sirven si $f$ es singular en los extremos.

Peligro de orden alto

Para $N \geq 8$ los pesos alternan de signo y crecen mucho ($272400$, $-260550$, …) → riesgo de cancelación catastrófica.

Ejemplo 4.5 · Más allá de Newton-Cotes

Cuadratura de Gauss

La idea genial

Newton-Cotes fija los puntos equiespaciados y solo optimiza los pesos. Gauss también optimiza dónde poner los puntos.

El conteo

Con $N$ puntos hay $2N$ incógnitas ($N$ pesos $+$ $N$ posiciones) → se pueden imponer $2N$ condiciones → exactitud hasta grado $2N-1$.

$$\int_a^b f(z)\,dz \approx \frac{b-a}{2}\sum_{k=1}^{N} w_k f(z_k)$$

DEDUCCIÓN PARA $N=2$ EN $[-1,1]$

$2 = w_1 + w_2$
$0 = w_1x_1 + w_2x_2$
$\tfrac23 = w_1x_1^2 + w_2x_2^2$
$0 = w_1x_1^3 + w_2x_2^3$

Por simetría $x_2=-x_1$  ⟹  $w_1=w_2=1$ y

$$x_1 = \tfrac{1}{\sqrt3} = 0.5773503$$
Limitación

Los puntos de Gauss no son equiespaciados → no sirve para datos tabulados, solo para funciones evaluables donde uno quiera.

Cierre

Conclusiones

1

Integrar numéricamente es interpolar y luego integrar exacto. El grado del polinomio determina la regla: recta → trapecio, parábola → Simpson.

2

El Prog 4-1 combina las reglas $3/8$ y $1/3$ para manejar cualquier $N$: si es impar arranca con $3/8$ y deja un resto par. Salida verificada contra el libro.

3

Romberg da precisión gratis: combinando dos corridas del trapecio se pasa de $O(h^2)$ a $O(h^4)$ sin evaluar puntos nuevos.

4

La validación $\alpha\sum w = N$ agregada al Prog 4-2 detectó dos erratas en la tabla 4.2 del libro, y explica una "anomalía" que el texto atribuía a errores de redondeo.

5

Lección transversal: nunca confiar en una tabla sin validarla. Una condición de consistencia simple ahorra horas de depuración.
