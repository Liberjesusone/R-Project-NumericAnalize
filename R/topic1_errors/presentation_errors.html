Introducción

¿Por qué existen errores?

"El eficiente y preciso uso de los resultados numéricos requiere considerable experiencia y avanzados conocimientos para evitar desatinos."

  • Las computadoras representan números con precisión finita — número fijo de bits
  • Los algoritmos numéricos aproximan procesos matemáticamente infinitos (series, límites, integrales)
  • Los datos de entrada ya contienen imprecisiones propias del mundo físico o de mediciones

Consecuencia: toda solución numérica contiene error. El objetivo es controlarlo y cuantificarlo.

Clasificación

Las Fuentes Principales de Error

Error del Modelo

Las hipótesis o condiciones físicas son incorrectas o demasiado simplificadas.

Error del Método

Se formula una aproximación cuando el problema exacto no tiene solución directa.

Error Residual

Series infinitas truncadas a un número finito de términos.

Error Inicial

Parámetros de entrada con valores solo aproximadamente conocidos.

Error de Redondeo

Representación finita de los números en la memoria — el más analizado hoy.

Error de Operación

Operaciones sobre números aproximados o aproximaciones de operaciones exactas.

Causa principal Nº 1

Error de Truncamiento

Ocurre al aproximar un proceso infinito con uno finito. El caso más importante: la Serie de Taylor.

f(x) = f(a) + h·f′(a) + (h²/2!)·f″(a) + (h³/3!)·f‴(a) + ···

Al truncar en el término N, el error cometido es:

O(hN+1) = hN+1/(N+1)! · f(N+1)(a + ξh), 0 ≤ ξ ≤ 1

Cuanto mayor N (más términos), menor error de truncamiento — pero mayor costo computacional.

Dígitos significativos

Números subnormales

Cuando el número cae por debajo de 2⁻¹⁰²² el exponente se congela en −1022 y la mantisa pierde un bit por cada halving. Permiten 52 pasos extra antes de llegar a cero — de ahí que el underflow tome 1022 + 52 + 1 = 1075 iteraciones desde 1.0.

Cancelación por absorción

Si sumas un número enorme con uno diminuto cuya diferencia de magnitud supera los 15–16 dígitos de precisión, el pequeño desaparece sin dejar rastro: A + B = A. El orden de operaciones en una suma importa.

Error de Redondeo

Epsilon de Máquina

El número más pequeño ε tal que la computadora puede distinguir 1 + ε de 1:

εm = 2−52 ≈ 2.22 × 10−16
# Cálculo del epsilon de máquina
epsilon <- 1.0
while ((epsilon / 2 + 1) > 1) epsilon <- epsilon / 2
cat("Epsilon calculado: ", epsilon, "\n")
cat("Valor en .Machine:", .Machine$double.eps, "\n")

Epsilon calculado:  2.220446e-16
Valor en .Machine:  2.220446e-16

Precisión relativa, no absoluta

El gap entre floats consecutivos depende de la magnitud:

  • cerca de   1  → gap = 2⁻⁵²
  • cerca de   2  → gap = 2⁻⁵¹
  • cerca de 0.5 → gap = 2⁻⁵³

La precisión es siempre 2⁻⁵² × magnitud.

Cuándo se pierden dos números

Dos números son indistinguibles si su diferencia es menor que 2⁻⁵² × su magnitud. La absorción ocurre cuando la razón entre ellos supera 2⁵² ≈ 10¹⁶:

  • 10¹⁰⁰ + 10⁸³ → razón 10¹⁷ > 10¹⁶  ✗ se absorbe
  • 10¹⁰⁰ + 10⁸⁵ → razón 10¹⁵ < 10¹⁶  ✓ sobrevive
Desbordamiento

Overflow y Underflow

Overflow

Número mayor que el máximo representable → la computadora devuelve Inf

Underflow

Número menor que el mínimo positivo → la computadora lo redondea a 0

# Overflow: multiplicar por 2 hasta Inf
x <- 1.0; i <- 0
while (is.finite(x)) { x <- x * 2; i <- i + 1 }
Overflow despues de 1024 multiplicaciones  →  Inf

# Underflow: dividir por 2 hasta 0
y <- 1.0; j <- 0
while (y > 0) { y <- y / 2; j <- j + 1 }
Underflow despues de 1075 divisiones       →  0
Medidas del Error

Error Absoluto, Relativo y Porcentual

Sea A el valor exacto y a la aproximación:

Medida Fórmula Descripción
Error absoluto ξa = |A − a| Diferencia directa en las unidades del problema
Error relativo δa = ξa / |A| Proporción del error respecto al valor exacto
Error porcentual εa = δa × 100% Error relativo expresado en porcentaje

Ejemplo: Si A = π = 3.14159… y a = 3.1416, entonces
ξa ≈ 7.3 × 10⁻⁶ · δa ≈ 2.3 × 10⁻⁶ · εa ≈ 0.00023%

Conclusiones

  • 1Todo resultado numérico contiene error — entenderlo es parte del método
  • 2El error de truncamiento crece con menos términos en la serie; el de redondeo es intrínseco al hardware
  • 3El epsilon de máquina (~2.22 × 10⁻¹⁶) es el límite de precisión relativa en doble precisión
  • 4Overflow e underflow son consecuencias directas de los 11 bits del exponente
  • 5Siempre medir el error de forma relativa — el error absoluto sin contexto no dice nada
