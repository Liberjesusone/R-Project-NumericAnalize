Motivación

¿Qué es la interpolación?

El problema

Datos conocidos: $n+1$ pares $(x_i,\, f(x_i))$.
¿Cómo estimar $f(x)$ en un punto intermedio?

La solución

Construir un polinomio $P(x)$ de grado $\leq n$ que pase exactamente por todos los puntos.

Unicidad

Dados $n+1$ puntos con $x_i$ distintos, existe un único polinomio de grado $\leq n$ que los interpola.

Interpolación vs Extrapolación

Interpolación: $x$ entre los datos — precisa.
Extrapolación: $x$ fuera del intervalo — el error crece rápidamente.

Fórmula directa

Interpolación de Lagrange

$$P(x) = \sum_{k=0}^{n} L_k(x)\cdot f(x_k)$$
$$L_k(x) = \prod_{\substack{j=0\\j\neq k}}^{n} \frac{x - x_j}{x_k - x_j}$$
  • $L_k$ vale $1$ en $x_k$ y $0$ en todos los demás nodos — actúa como "selector".
  • Desventaja: añadir un nuevo punto obliga a recalcular todos los $L_k$ desde cero.
  • Newton resuelve esto con tablas de diferencias — agregar un punto solo añade una columna nueva.

Extrapolación

Si $x < x_0$ o $x > x_n$, el programa imprime advertencia pero continúa calculando.

Costo

$O(n^2)$ multiplicaciones. Con $n+1 = 4$ puntos: exactamente $12$ productos por evaluación.

Programa 2-3 · Datos de cualquier espaciado

Diferencias divididas de Newton

$$f[x_i] = f(x_i)$$ $$f[x_i, x_j] = \dfrac{f[x_j] - f[x_i]}{x_j - x_i}$$
$$P(x) = f[x_0] + f[x_0,x_1](x-x_0)$$ $$\quad + f[x_0,x_1,x_2](x-x_0)(x-x_1) + \cdots$$
Ventaja clave

Agregar $x_{n+1}$ solo requiere calcular una nueva columna. Los coeficientes anteriores no cambian.

Relación con diferencias $\Delta$

Con datos equiespaciados, las diferencias divididas se reducen a diferencias hacia adelante divididas por potencias de $h$.

Análisis de error

Error de truncamiento

$$E(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!} \cdot \prod_{i=0}^{n}(x - x_i), \qquad \xi \in \bigl(\min_i x_i,\; \max_i x_i\bigr)$$
  • Más nodos ($n$ mayor) → el error típicamente decrece, pero no siempre.
  • Fenómeno de Runge: para $f(x) = \dfrac{1}{1+x^2}$ con nodos equiespaciados, aumentar $n$ empeora el error en los extremos.
  • Error vs redondeo: sumar muchos términos introduce errores acumulativos — hay un $n$ óptimo.
  • Extrapolación: el producto $(x-x_0)\cdots(x-x_n)$ crece rápido fuera del intervalo — evitarla.
